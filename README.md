# Efficient Inversion of Unknown Unitary Operations with Structured Hamiltonians

**Maintainer:** Tengxiang Lin (<tengxianglin23@gmail.com>)

This repository contains the code accompanying the paper  
**“Efficient Inversion of Unknown Unitary Operations with Structured Hamiltonians”**.  
We develop structured Hamiltonian ansätze and quantum‐comb protocols to invert unknown unitaries generated by these Hamiltonians, with applications to Hamiltonian sampling and noise‐robustness analysis.

## Repository Structure

- **search_comb_for_specific_unitaries.py**  
  Script to search optimal comb configurations (slots/parallel/ancilla) for inversion, conjugation, or transposition of a Hamiltonian with given Pauli supports.  
  By modifying the `target_func` to the appropriate batch-processing function, the script can target inversion, conjugate, or transpose operations.

- **pauli_solution_search.py**  
  Script to find explicit Pauli‐gate sequences that invert unknown unitaries via `pauli_gate_solutions`.
  By modifying `target_func`, you can search for solutions to invert, conjugate, or transpose, etc.
  You can also adjust `num_slots` to obtain solutions for different numbers of comb slots.

- **validate_V_finder_efficiency.py**  
  For unitaries satisfying the conditions of Theorem 1 and Theorem 5 which can be transformed to their inverse, transpose, or conjugate by a Pauli operator `V`, this script validates the efficiency of the algorithm for finding `V`.

  For unitaries that can be transformed to their inverse satisfing the condition of Theorem 3, it gives the anticommuting set solution $\{V_i\}$ for its inverse.

  Validates the efficiency and uniqueness of the mapping algorithm using a 1-slot Pauli example, with tunable parameters for transformation mode, number of qubits, support set size, and sorting strategy.

- **utils/hamiltonian_utils.py**  
  Core routines for Pauli‐based Hamiltonian manipulation, including  
  - generation of random and full Pauli operator lists  
  - Hamiltonian‐parameterized unitary sampling (`_generate_unitaries`)  
  - type‐classification of Pauli sets (`H_type`, `is_type_*`)  
  - comb‐based inversion search (`HamiltonianPQCombNet`, `pauli_gate_solutions`)

- **utils/comb.py**  
  Implementation of the PQCombNet class and related training routines.  
  - Quantum‐comb construction
  - Fidelity evaluation and training loops

- **robustness_analysis.py**  
  Testing the robustness of the protocols in the article (1‐slot, 3‐slot, recurrence 7/15 slots) by Monte‐Carlo noise‐simulation routines, use Choi‐state fidelity under perturbations as the figure of merit.

- **IBM_noise_simulation.py**  
  Script to perform noise simulations on IBM Quantum backends. For each Pauli support in `PAULI_SUPPORTS_WITH_GATE`, it generates random unitaries, constructs ideal and noisy circuits via `build_circuits`, simulates with Qiskit Aer, and computes average Choi‐state fidelity.

## Usage

### 1. Search for Optimal Comb Configurations
Run with default settings:
```bash
python search_comb_for_specific_unitaries.py
```
To customize parameters, edit `search_comb_for_specific_unitaries.py`:
```python
TARGET_FUNC = conj         # or 'transpose', 'dagger'
PAULI_SUPPORTS = [...]     # list of Pauli-term lists
SLOTS = [1, 3]             # slots range or single value
PARALLELS = [1, 2]         # parallels range or single value
ANCILLA = 2                # number of ancilla qubits
```
Search proceeds by first increasing `SLOTS`, then `ANCILLA`, and finally `PARALLELS` until a valid solution is found.

### 2. Find Pauli-Gate Inversion Solutions
Run default one-slot search:
```bash
python pauli_solution_search.py
```
To change settings, edit `pauli_solution_search.py`:
```python
NUM_SLOTS = 2               # use 2 slots
TARGET_FUNC = dagger        # or 'conj', 'transpose'
PAULI_SUPPORTS = [...]      # custom Pauli term lists
RETURN_ALL = True           # True→return all solutions; False→stop on first found
```
When `RETURN_ALL = True`, the script returns all found solutions. If set to `False`, it stops after the first successful mapping and returns a boolean indicator. The function supports passing multiple Pauli-support lists at once, returning results in the same order.

### 3. Validate Unique Mapping Operator V
Validation script for algorithm efficiency using a 1-slot Pauli example.  
Generates a random Pauli operator `V` as the unique 1-slot solution, then constructs a Pauli support of specified size whose only valid mapping operator is `V`. Measures execution time and asserts uniqueness.

Run default validation:
```bash
python validate_V_finder_efficiency.py
```
To adjust test mode or scale, edit the top of `validate_V_finder_efficiency.py`:
```python
MODE = "transpose"          # 'dagger', 'transpose', 'conj'
NUM_QUBITS = 10             # number of qubits
TARGET_COUNT = 10**5        # support set size
```

### 4. Robustness Analysis Under Noise
Run all noise simulations:
```bash
python robustness_analysis.py
```
To change Monte Carlo parameters, modify calls in `robustness_analysis.py`:
```python
fidelity = comb_1slot_noise_simulation(delta=0.1, size=2000, num_qubits=4)
fidelity = comb_3slot_a_noise_simulation(delta=0.05, size=1500, num_qubits=3)
```
Results are saved to `robustness_results.csv`.

### 5. Interactive V-Transpose Search Notebook
Launch the notebook:
```bash
jupyter notebook search_U_transpose_coeff.ipynb
```
Inside the first code cell you can modify:
```python
PAULI_SUPPORT = ['Y0', 'Y1', 'Y0,Y1']
```
and re-run it— the notebook will automatically generate the corresponding parameterized circuits.
