# Query cost of suppressing parity phase drift

For the fully fielded odd Ising cycle, three parallel forward queries suffice for [exact inversion](THEORY_ODD_CYCLE_THREE_QUERIES.md). Here we consider clean parallel protocols with a fixed isometric encoder, an inverse decoder and any finite workspace on which the oracle does not act. The protocol may implement the ideal inverse up to a single global phase. A query count $m$ means exactly $m$ unconditional copies of the oracle in the parallel layer.

**Results.** The possible query counts for exact clean parallel inversion are precisely $m=3\bmod 4$. Every three-query protocol in this class has the same linear sensitivity to common parity phase drift. Seven queries are necessary and sufficient within the class to retain ideal exact inversion and eliminate the linear response to that drift. The seven-query construction below gives cubic conditional error when checking clean return.

## Why three queried sectors must agree

Write $P=\prod_j X_j$, $\Pi_s=(I+sP)/2$ and $S_s=\operatorname{ran}\Pi_s$ for $s=\pm1$. Use the ordered Majoranas from the [explicit encoder](THEORY_ODD_CYCLE_THREE_QUERIES.md#quadratic-representation-in-the-two-sectors). Let $L_{ab}=\gamma_a\gamma_b$ for $a\ne b$. The physical anti-Hermitian generators, up to signs, consist of consecutive bilinears along the Majorana path and one boundary bilinear multiplied by $P$. The rule $[L_{ab},L_{bc}]=2 L_{ac}$ for distinct labels gives all ordinary bilinears from the path. Since $P$ commutes with bilinears, taking commutators of the boundary generator with ordinary bilinears gives all $PL_{ab}$ as well. For example a fixed $PL_{ab}$ first gives $PL_{ac}$ for every $c\ne a,b$, and two commutator steps with ordinary bilinears then cover pairs not containing $a$. Hence the real Lie algebra generated by the promise contains the separately supported $\Pi_+ L_{ab}$ and $\Pi_- L_{ab}$. These span the algebra since they are closed under commutators. The same commutator rule inside each projected algebra shows that it is perfect, meaning that the commutators span it.

Let $E$ denote a candidate encoder. For every individual real Hamiltonian generator $H_j$, clean exact inversion of $e^{-itH_j}$ implies
$$
(e^{-itH_j})^{\otimes m}E=e^{i\phi_j(t)}E\,\overline{e^{-itH_j}},
$$
with the tensor identity on the unqueried workspace implicit. The phase can be chosen differentiably near $t=0$, for instance by extracting the scalar from the compression against the target. Differentiating makes the encoded space invariant under each tensor-power Lie generator, and thus under their linear combinations and commutators. On that space the action is the conjugate input generator plus an imaginary scalar. The scalar defines a linear functional on the generated Lie algebra and vanishes on every commutator. Perfection therefore makes it identically zero. Exponentiating yields the exact intertwiner for group elements generated by this algebra. This step uses the representation property of a parallel query layer.

In the block supported on $S_s$, exponentiate the commuting generator $\tfrac{\pi}{2}\sum_j\Pi_s a_j b_j$. The resulting operator is identity on $S_{-s}$ and acts on $S_s$ by $c_s=(-i)^n s$, since $\prod_j a_jb_j=(-i)^nP$. For odd $n$ this is a primitive fourth root. For input in $S_s$, the effective target action of this element is $\overline{c_s}=c_s^3$. If $r_s$ query registers have parity $s$, their eigenphase is $c_s^{r_s}$. The matching conditions for the two independently supported central elements require
$$
r_s\equiv3\pmod4,\qquad r_{-s}\equiv0\pmod4.
$$
This holds for every query parity pattern in the image of $S_s$, including when the workspace is entangled with the queries. It implies $m\equiv3\pmod4$. For $m=3$ all queried sectors must agree with the data sector. Conversely, the explicit three-query construction can be padded by any number of four-query invariant states constructed below.

## Exact drift response and a seven-query construction

Suppose each slot uses $e^{-i(H+\epsilon P)}$ in place of $U=e^{-iH}$. This models a common coherent relative phase between the two $P$ sectors. Because $[P,H]=0$, the three-query parity constraint forces the decoded data unitary to be $U^\dagger e^{-i3\epsilon P}$ for every clean parallel encoder. Its diamond distance from the ideal channel is $2|\sin(3\epsilon)|$. To see this, a pure input, possibly with a reference, gives an overlap in the line segment joining the two eigenphases $e^{\pm i3\epsilon}$, with minimum modulus $|\cos(3\epsilon)|$ at equal weights. There is no auxiliary leakage in this drift model at three queries.

For each $s$, define $f_{sj}=\operatorname{vec}(T_j)/\sqrt D$ in $S_s^{\otimes 2}$, using the notation and real bases of the [three-query construction](THEORY_ODD_CYCLE_THREE_QUERIES.md#a-fixed-encoding-for-odd-numbers-of-fermionic-modes). They are orthonormal and transform by the same real orthogonal matrix under the double oracle on that sector. Thus
$$
\Omega_s=(2n)^{-1/2}\sum_j f_{sj}\otimes f_{sj}
$$
is normalized and invariant under four copies of the oracle. For an input in $S_s$, append to the three-query encoder the state
$$
\frac{1}{\sqrt8}\Omega_s+\sqrt{\frac78}\,\Omega_{-s}.
$$
This appending is a fixed coherent isometry because the first three queried registers preserve the sector label. The invariant states imply exact inversion under the ideal seven-fold oracle.

The total query parity $\sum_{j=1}^7 P_j$ has eigenvalue $7s$ on the first branch of the appended state and $-s$ on its second branch. Their weighted mean vanishes. With clean-return postselection the drift multiplies the output in $S_s$ by
$$
F_s(\epsilon)=\tfrac18e^{-i7s\epsilon}+\tfrac78e^{is\epsilon}.
$$
The modulus is the same in both sectors, so success is input independent with probability $1-7\epsilon^2+O(\epsilon^4)$. The accepted phase is $\arg F_s(\epsilon)=7s\epsilon^3+O(\epsilon^5)$ near zero. The conditional diamond error is $14|\epsilon|^3+O(|\epsilon|^5)$. The unconditional channel has no first-order term, since compression of total query parity is zero and the leakage probability is quadratic. The congruence obstruction excludes four, five and six unconditional parallel queries and the three-query result is linear. Thus seven is the minimum in this class for first-order suppression of the stated drift.

The four-query spectator state also shows sufficiency for every ideal query count $m=3+4k$ by tensoring $k$ invariant states in a known sector. The lower bounds here concern clean parallel protocols. Sequential protocols, general decoders with oracle-dependent environment output, and the known-gate cost of the seven-query encoder remain open.

## Verification

The following finite check closes the Pauli labels under commutators for four small odd sizes, then checks the parity patterns and the exact rational moments of the seven-query drift. The proof gives the result for all odd sizes.

~~~python
from itertools import combinations, product


def verify(n):
    majoranas = []
    for j in range(n):
        prefix = (1 << j) - 1
        majoranas += [(1 << j, prefix), (1 << j, prefix ^ (1 << j))]

    def multiply(left, right):
        return left[0] ^ right[0], left[1] ^ right[1]

    def anticommute(left, right):
        return ((left[0] & right[1]) ^ (left[1] & right[0])).bit_count() % 2

    parity = (0, (1 << n) - 1)
    bilinears = {multiply(a, b) for a, b in combinations(majoranas, 2)}
    expected = bilinears | {multiply(parity, op) for op in bilinears}
    assert len(expected) == 2 * len(bilinears)
    closure = {multiply(a, b) for a, b in zip(majoranas, majoranas[1:])}
    closure.add(multiply(parity, multiply(majoranas[-1], majoranas[0])))
    frontier = set(closure)
    while frontier:
        new = {
            multiply(left, right)
            for left in frontier for right in closure
            if anticommute(left, right)
        } - closure
        closure |= new
        frontier = new
    assert closure == expected

    for s in (1, -1):
        phase = (-1j) ** n * s
        allowed = [
            word for word in product((1, -1), repeat=3)
            if phase ** word.count(s) == phase.conjugate()
        ]
        assert allowed == [(s, s, s)]
    print(f"n={n}: {len(closure)} Lie-generator labels, both sector constraints verified")


for n in (3, 5, 7, 9):
    verify(n)


# Seven-call weights. Both moments and the success loss are determined
# by the two parity charges, 7 and -1, for the positive sector.
from fractions import Fraction

weights = (Fraction(1, 8), Fraction(7, 8))
moments = [sum(w * q**k for w, q in zip(weights, (7, -1))) for k in range(4)]
assert moments == [1, 0, 7, 42]
print("Seven-call normalized charge moments:", moments)
~~~
