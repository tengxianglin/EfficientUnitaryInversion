# Exact perfect-matching ensemble for the balanced-slice even-minor moments

Date: 2026-11-26. This is an exact positive-ensemble construction in the unrestricted special-orthogonal group. It is a relaxation benchmark for the EUI physical problem, **not** yet an ensemble of the fixed nearest-neighbour cycle Hamiltonian family.

## 1. General theorem

Let N=2n, index coordinates by 0,...,2n-1, and set
\[
D=\operatorname{diag}(1,-1,1,-1,\ldots,1,-1).
\]
For a perfect matching M of these 2n coordinates, let P_M be the permutation matrix that swaps the two endpoints of every matching edge. Define
\[
R_M=P_M D.
\]

**Theorem.** Every R_M belongs to SO(2n). If I is a subset of [2n] with even size |I|=2r, then
\[
\det (R_M)_{I,I}
=(-1)^{\sum_{i\in I}i+r}
\mathbf 1\{I\text{ is a union of }r\text{ edges of }M\}.
\]
For uniformly random perfect matching M,
\[
\boxed{
\mathbb E_M\det (R_M)_{I,I}
=(-1)^{\sum_{i\in I}+r}
\frac{\binom nr}{\binom{2n}{2r}}.
}
\]

### Proof

A perfect matching is a product of n disjoint transpositions, so P_M is orthogonal with determinant (-1)^n. Also D is orthogonal and has exactly n negative diagonal entries, hence det D=(-1)^n. Therefore R_M=P_MD belongs to SO(2n).

The principal submatrix is (R_M)_{I,I}=(P_M)_{I,I}D_{I,I}. If any vertex of I is matched outside I, the corresponding row of (P_M)_{I,I} is zero and its determinant vanishes. If I is closed under the matching, the restricted permutation is exactly r disjoint transpositions, so its determinant is (-1)^r; multiplication by D_{I,I} contributes (-1)^(sum i in I). This proves the pointwise identity.

The number of perfect matchings of 2n vertices is (2n-1)!!. The number that pair all vertices of a fixed 2r-set internally is
\[
(2r-1)!!\,(2n-2r-1)!!.
\]
Thus
\[
\Pr(I\text{ is matching-closed})
=\frac{(2r-1)!!(2n-2r-1)!!}{(2n-1)!!}
=\frac{\binom nr}{\binom{2n}{2r}},
\]
which gives the formula.

## 2. Identification with the balanced Hamming-slice target

Let T be uniform over all n-subsets of [2n], and define balanced signs
\[
x_i=(-1)^{\mathbf 1\{i\in T\}}.
\]
Exactly n signs are +1 and n are -1, so sum_i x_i=0 deterministically. By exchangeability, let mu_2r=E[product_{i in I} x_i] for any fixed 2r-set I. Multiplying sum_i x_i=0 by a product over a fixed (2r-1)-set and taking expectations yields
\[
(2r-1)\mu_{2r-2}+(2n-2r+1)\mu_{2r}=0,
\qquad \mu_0=1.
\]
Consequently
\[
\mu_{2r}=(-1)^r\frac{(2r-1)!!}{(2n-1)(2n-3)\cdots(2n-2r+1)}
=(-1)^r\frac{\binom nr}{\binom{2n}{2r}}.
\]
Since product_{i in I} x_i=(-1)^{|I intersect T|}, the perfect-matching ensemble obeys
\[
\mathbb E_M\det (R_M)_{I,I}
=(-1)^{\sum_{i\in I}i}
\mathbb E_T(-1)^{|I\cap T|}.
\]
Equivalently, it reproduces exactly the repository's target convention
\[
\operatorname{target}(n,I)
=(-1)^{\sum_{i\in I}i+r}
\frac{\binom nr}{\binom{2n}{2r}},
\qquad |I|=2r.
\]

## 4. Crucial physical limitation

The matrices R_M=P_MD are signed permutation matrices indexed by arbitrary perfect matchings of the complete graph. The EUI physical family audited in this repository is generated by a fixed cyclic nearest-neighbour skew matrix
\[
A(c)_{j,j+1}=2c_j,\qquad
A(c)_{j+1,j}=-2c_j
\]
(with cyclic indices), and matrices e^{A(c)}. The matching theorem does **not** show that arbitrary R_M lie in this restricted exponential family, nor that they can be implemented using only the controls allowed in the inversion protocol.

Thus this is an exact positive ensemble for the unrestricted SO(42) relaxation and a sharp diagnostic of where the remaining difficulty lies: **physical reachability / convex-hull membership for the fixed cycle family**. The 204-column finite-pool obstruction is not contradicted because its columns are a small set of physical cycle evolutions, not the complete perfect-matching orbit.
